🧭 Compass - Better Code Navigation

Lost? Tired of endlessly scrolling through tabs just to find the previous file you were working on?

Compass provides you the list of most-recently used tabs. It also helps you filter them by special tags!

By default, `ctrl+tab` jumps you to the next view in the MRU stack without showing the stack.
Compass provides you a visual guide of where you have been.

---

### How To Use

You must first enable the keybindings. From the command palette, select `Compass: Keybindings`
The plugin already has pre-commented keybinds that you can just copy

### What's new in 3.0.4 ✨

Big round of bug fixes this time — if something felt off before, it's probably fixed now.

Tabs that vanished from Compass after a restart, wrong files when navigating, projects bleeding into each other's stacks — all patched. Multi-selected tab groups (Ctrl+click) finally stay put the way you'd expect.

Other things we squashed:
- Every open window now restores its own tab history, not just the last one
- A crash when closing windows mid-operation

New setting:
  "stack_cache_throttle": 30

This one's for the power users — it controls how often your tab history is saved to disk. Bump it up if you're on a big project and want to cut down on writes. Minimum is 30.

### What's new in 3.0.5 ✨

A short one: if Compass wouldn't load after installing or updating, this release fixes it. A missing internal marker meant zip installs (`Installed Packages`) couldn't import the plugin — source-install users were unaffected. No new features, just getting the wheels back on.
